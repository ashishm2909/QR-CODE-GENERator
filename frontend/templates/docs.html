Getting Started

Welcome to the QRNation API. Our API allows you to programmatically generate and manage high-quality QR codes for your applications.

Base URL

https://api.qrnation.com/v1

Quick Example

curl -X POST https://api.qrnation.com/v1/generate \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d "data=https://qrnation.com" \
  -d "type=url"
